# Changelog

All notable user-facing changes to Vox are documented here.

The authoritative, per-build release notes live in the
[vox-releases](https://github.com/KlymSerhii/vox-releases/releases) repository —
that's also what the in-app auto-updater reads. This file is a human-readable
summary that follows [Keep a Changelog](https://keepachangelog.com/) and
[Semantic Versioning](https://semver.org/).

## [Unreleased]

- Vox is now open source under the MIT License and free for everyone, including
  companies and teams using it at work. It replaces the PolyForm Noncommercial
  license, which required a paid license for company or team use.
- Public repository: added README, LICENSE, and contributor /
  security / third-party documentation.
